# Build decisions before the action-plan research

## Question

What has the student decided before a deep-research pass writes the action plan?

## Answer

Asked 2026-10-17, before any research workflow. The student wants a step-by-step action plan, then parallel agents. These answers constrain that plan.

### Who writes the code

Agents write the app. The student may record a demo later.

On the second pass the student said to finish the app and not plan around the contest rule that AI cannot be the whole technical development. Submission is a deadline they want as motivation. They may not submit. The plan still discloses Grok's role on the about page. It does not block the build on a student-written file.

### Where it runs

The student can get hosting and bandwidth for the project duration and can buy a public URL. They assume AWS. They do not have an account ready. They said credits might come later through an API key.

[[scope]] had said a local Python server is enough for judging. Hosting is now wanted. The research plan should name an AWS shape that can start without credits, keep a local run, and say what the credits would change.

### What the page shows

The page is one screen with two equal parts. One part is a form for the eight XGBoost features. One part is a browser of the stored years. A search by name, city, or NPI fills the form from the stored row. Typing scores a new row. Years are 2018–2024. The disclaimer stays: a score is a resemblance, not a fraud finding.
