# Congressional App Challenge vault

Medicare Fraud Flagger. The page scores a public billing row. A high score is a resemblance to providers later excluded for a fraud-type reason. It is not a finding that the firm committed fraud.

The Medicare files and the saved ranker are not in git. `DATA.md` says where to download them and which folder each file belongs in. A clone can run the unit tests. The page stops and names the missing files until those downloads are in place.

Obsidian vault and agent workspace for one 2026 Congressional App Challenge entry.

Open this folder in Obsidian as a vault. The agent schema is `WIKI.md`. Contest rules for the agent are in `AGENTS.md`. The wiki catalog is `wiki/index.md`.

Karpathy's LLM Wiki idea file is imported at `raw/sources/karpathy-llm-wiki.md`. Do not edit files in `raw/`.
