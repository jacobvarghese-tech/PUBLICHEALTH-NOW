Pattern Check

What this score is

A high score means the public billing row looks unusual next to other billers of the same service in the same year. It does not mean the biller committed fraud.

Why there is no fraud classifier

The first plan was a supervised model whose positive class would be “this biller was later sanctioned for a scheme built on medically unnecessary services.” That plan needed at least 50 unique positive NPIs, spread across more than one scheme, each of whom billed a watched code in a year before the sanction date. The joined count did not clear that gate.

Label counts load with the data file.

The current HHS OIG exclusion list, downloaded October 15, 2026, has 84,093 records. Fraud-type records (1128(a)(1), 1128(a)(3), 1128(b)(6), 1128(b)(7)) number 32,790, and 4,296 of those have a usable NPI. License revocations are a larger category and are not treated as fraud labels. A match also does not mean the person was excluded for the service in the row. The reason code does not name an HCPCS code.

On the genetic-test slice, five fraud-type matches appeared, all kickback exclusions (1128(b)(7)), none the medically unnecessary code 1128(b)(6). A wider 2022–2024 scan of COVID testing, remote monitoring, nerve conduction, urine drug testing, allergy testing, skin-graft application, respiratory PCR, and a few genetic codes joined to 29 unique fraud-type NPIs once every watched code for 2022–2024 was included. Adding the catheter and skin-substitute joins does not get the count to 50. That number is a join result, not a conviction count.

Three later searches were run on October 15, 2026:

  • DMEPOS referring-provider catheter codes A4351, A4352, and A4353, years 2021–2024, covered 22,550 referring NPIs and joined to 3 fraud-type exclusions. The supplier file for the same codes covered 2,225 NPIs and joined to none. Fifty-five skin-substitute Q codes in the physician file, 2022–2024, joined to 2. Together that search added 5 unique fraud-type NPIs, and all 5 billed in a year before the exclusion year. Four are 1128(a)(1) and one is 1128(b)(7).
  • Wayback Machine copies of the exclusion file from 2022, 2023, 2024, and January 2026 recovered 282 fraud-type NPIs that the current file no longer lists. Ten of those are kickback exclusions. None are 1128(b)(6). Those NPIs were not joined back to billing rows, so they do not add confirmed positives.
  • Department of Justice takedown summaries name owners, marketers, and ordering clinicians more often than the rendering NPI on the billing row. Named labs that resolve in the NPPES registry are listed below. Convictions and settlements are kept apart from charges. An indictment is a charge.

Part D opioid files were left out. They are a different kind of case and would only inflate the count.

How the score is built

For one HCPCS code and one year, each rendering NPI gets four numbers, all compared with other billers of that same code:

  1. National share: this biller’s services divided by all services for the code that year.
  2. ZIP share: services from this biller’s ZIP code divided by national services for the code.
  3. Growth: this year’s services divided by the same NPI and code last year, minus one. A new biller is left blank and does not add to the score.
  4. Charge ratio: average submitted charge divided by the median charge for the code and year.

Each number is turned into a 0–1 rank among that year’s billers. The score is 40% national share, 25% ZIP share, 20% growth, and 15% charge ratio. Missing growth is left out of that biller’s average so a new lab is not punished or rewarded for a blank. The weights are a ranking choice, not a trained model.

Libraries, tools, and AI

  • HTML, CSS, and JavaScript. No framework. The page runs by opening index.html or by serving the app folder.
  • Public data: CMS Medicare Physician & Other Practitioners by Provider and Service, data.cms.gov. Years used: 2022, 2023, 2024.
  • HHS OIG List of Excluded Individuals/Entities, UPDATED.csv, downloaded October 15, 2026, plus Wayback Machine snapshots of that file.
  • CMS NPPES NPI Registry API, used to resolve legal names to NPIs.
  • Python scripts in the working notes prepared the JSON. They are not part of the running page.
  • AI use: Grok, in the Grok Build CLI, was used to query the public files, count label joins, and draft this page and the ranking code. The ranking formula, the decision not to train a classifier, and the wording that a score is not a fraud finding were checked against the joined counts. The student should describe their own part of the build in the portal, in their own words.

What a 2.0 could add

A classifier only if a later label source clears 50 unique positives across more than one scheme, with a year split and a top-1% and top-5% capture rate. Until then, the honest tool is this ranking.
